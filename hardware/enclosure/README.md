# Printed Enclosure

The working prototype uses a 3D-printed enclosure with separate top, bottom, and button pieces. The models are provided as STL meshes.

## Models

| File | Part |
|---|---|
| [Top_Case.stl](Top_Case.stl) | Top enclosure section |
| [Bottom_Case.stl](Bottom_Case.stl) | Bottom enclosure section |
| [Button (1).stl](<Button (1).stl>) | Separate button piece |

## Hardware Integration

The enclosure forms the physical housing for the display and custom PCB. The button piece provides the external interface to the momentary switch used for navigation and LCD recovery.

The [hardware overview](../README.md) covers the electronics, and the [design specification](../../docs/design.md#user-interaction) defines the button controls.
